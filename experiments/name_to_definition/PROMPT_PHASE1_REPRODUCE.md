# 任务：优先复现 SGAgent 原始定位实验

请暂时不要进行 name-to-definition 消融。第一阶段目标是依据 SGAgent 论文和官方实验仓库，尽量复现原始 Locator 实验及其指标，为后续 A/B 测试建立可信 baseline。

除 API 与模型服务必须使用当前可用的本机 qtapi（模型为 `claude-sonnet-5`）之外，其余部分应尽量与官方方案保持一致，包括：

- 使用官方代码路径、Locator 工作流和终止机制；
- 使用官方 prompt、工具定义、图索引和上下文压缩机制；
- 使用官方数据集、样本范围、输入格式和随机设置；
- 使用官方运行参数；不要沿用当前自定义实验的 12 轮限制；
- 使用官方 File/Function 指标定义及 evaluator；
- 不修改、隐藏或增强 `find_methods_by_name`、`find_all_variables_named` 等工具；
- 保存每条完整 trajectory，包括消息、工具调用、工具返回、token usage、最终预测、终止原因、耗时和真实模型标识。

实施步骤：

1. 阅读论文、官方 README、配置和评测代码，列出论文配置、官方仓库配置与当前环境之间的差异。
2. 固定并记录官方仓库 commit、数据集版本、依赖版本、运行命令和随机种子。
3. 只添加必要的 qtapi 模型适配层，避免改变 agent 行为；明确记录所有无法与官方一致的地方。
4. 先运行 5～10 个样本做 smoke test，确认绝大多数样本能正常输出定位结果，轨迹和 token 记录完整，官方 evaluator 可运行。
5. smoke test 通过后，在固定随机 45 个样本上运行复现实验并汇总 File Accuracy、Function Accuracy、完成率、token、工具调用次数、耗时和费用。
6. 将结果与论文官方指标比较，分析差异来源。不要因为指标较低而修改结果、丢弃失败轨迹或调整样本。

验收要求：

- 公共实验逻辑与官方实现一致，唯一预期差异是 API/模型服务；
- 所有必要改动应小而集中，可通过 diff 审计；
- 所有成功、失败、超时和预算耗尽轨迹均保留；
- 输出可复现运行命令、配置快照、逐实例结果、聚合报告和 reproduction gap report；
- 在确认 baseline 复现质量之前，不开始 N2D 消融实验。

如果官方模型已经不可用，不要求数值完全复现论文；应先证明实现、数据和评价口径一致，再把当前模型得到的结果作为后续消融实验的新 baseline。
